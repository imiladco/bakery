# Bakery Elementor Widgets

افزونهٔ اختصاصی ویجت‌های المنتور برای بیکری عظام — سه ویجت، یک افزونه، یک
دسته‌بندی مشترک (`بیکری عظام`) در پنل المنتور.

## ویجت‌ها

### آیکون، عنوان و توضیحات (`bakery-icon-box`)

سه بخش مستقل (آیکون، عنوان، توضیحات) با تگ HTML قابل‌انتخاب برای عنوان و
توضیحات، جایگاه آیکون قابل‌انتخاب (کنار عنوان یا کنار توضیحات)، و پوشش کامل
تب استایل برای هر سه بخش (تایپوگرافی، رنگ، پس‌زمینه، حاشیه، رادیوس، سایه،
پدینگ). آیکون SVG به‌صورت inline و پاک‌سازی‌شده رندر می‌شود تا رنگش از تب
استایل قابل تغییر باشد.

### قیمت (`bakery-price`)

نمایش قیمت محصول ووکامرس (فعلی/پیشین/واحد پول) با ترتیب و جایگاه کاملاً
آزاد برای هر سه بخش (کنترل `order` مستقل برای هر بخش). محصول متغیر: کمترین
قیمت بدون قیمت پیشین. قیمت صفر: متن دلخواه به‌جای عدد.

### تعطیلات هفته (`whw-weekly-holidays`)

هفت روز هفته‌ی فیزیکی جاری (شنبه تا جمعه، تقویم شمسی) با وضعیت مستقل هر روز:
**عادی** / **امروز** / **تعطیل** (اولویت ثابت `تعطیل > امروز > عادی`؛ کلاس
`.is-today` مستقل از رنگِ حالت همیشه روی کارت جاری می‌نشیند). تعطیلی از یک
زنجیره‌ی اولویت تعیین می‌شود: override روزانه ← انتخاب دستی ماهانه ← جمعه ←
عادی. یک «WHW Visibility Condition» هم به تب Advanced همه‌ی المان‌های
المنتور اضافه می‌شود تا بشود سکشن‌ها را بر اساس تعطیل/عادی بودن امروز
نمایش/مخفی کرد.

## ساختار

```
bakery-widgets.php           bootstrap مشترک هر سه ویجت (یک header، یک activation lifecycle)
includes/
  bakery/                    ویجت‌های Icon Box و Price — سبک رویه‌ای، require_once دستی، بدون autoloader
    plugin.php               ثبت دسته‌بندی «bakery» + دو ویجت + استایل
    svg.php                  پاک‌سازی SVG برای درج inline
    widgets/icon-box.php
    widgets/price.php
  Domain/                    منطق خالص تعطیلات هفته، بدون فراخوانی WP — قابل تست با PHPUnit خالص
    JalaliDate.php           تبدیل جلالی↔میلادی (پیاده‌سازی داخلی الگوریتم Borkowski، بدون وابستگی)
    Week.php                 محاسبه‌ی هفته‌ی فیزیکی + کلیدهای یکتای ماه شمسی
    Rules/                   Chain of Responsibility: Override → ماهانه → جمعه → پیش‌فرض
  Storage/                   آداپتورهای wp_options (autoload=false)، memoize درون‌ریکوئستی
  Service/                   Clock (تک‌نقطه‌ی wp_timezone)، WeekBuilder، TodayStatus
  Integration/                Widget تعطیلات هفته، Visibility Condition، Dynamic Tag
  Admin/                     پنل تنظیمات تعطیلات هفته (تقویم گرافیکی) + REST
  Cron.php                   بروزرسانی روزانه‌ی snapshot تعطیلات هفته (غیرمرجع؛ فقط interoperability)
  Plugin.php                 composition root تعطیلات هفته (ویجت خودش را در دسته‌ی «bakery» ثبت می‌کند)
data/                        دیتاست تعطیلات رسمی (اطلاع‌رسانی، بدون اثر در محاسبه)
assets/
  css/bakery-widgets.css     استایل ساختاری Icon Box/Price
  css/whw.css, whw-admin.css
  js/whw-admin.js
tests/
  Domain/, Service/          PHPUnit خالص برای تعطیلات هفته (بدون بوت‌استرپ وردپرس)
```

دو خانواده‌ی کد (`Bakery_Widgets\*` رویه‌ای، `WHW\*` autoload‌شده با namespace)
عمداً ادغام نشده‌اند — مستقل ساخته شده بودند و ادغام داخلی‌شان بدون سود واقعی
فقط churn بود. آنچه واقعاً یکی شده همان چیزی‌ست که وردپرس/المنتور می‌بینند:
یک header، یک چرخه‌ی activation، یک گیت نسخه‌ی PHP/المنتور، یک دسته‌بندی
ویجت مشترک.

تصمیمات کلیدی معماری بخش تعطیلات هفته (و چرایی‌شان) در تاریخچه‌ی گفتگوی
توسعه مستند شده‌اند؛ مهم‌ترین‌ها:

- **بدون وابستگی زمان اجرا** (نه Composer، نه هیچ کتابخانه‌ی بیرونی) — تبدیل
  جلالی پیاده‌سازی داخلی است، تست‌شده با round-trip روی ۵۵۰۰۰+ روز.
- **`whw_today_status_snapshot` (site option) مرجع تصمیم نیست** — فقط برای
  مصرف‌کنندگان بیرونی. تصمیم واقعی همیشه زنده از `Service\TodayStatus` گرفته
  می‌شود (ویجت، Visibility، Dynamic Tag).
- **Visibility Condition** پیاده‌سازی خودمان است، نه یک API خصوصی المنتور
  پرو (که در سورس عمومی قابل تایید نبود) — بر پایه‌ی فیلتر عمومیِ مستندِ
  `elementor/frontend/{type}/should_render` و هوک تزریق کنترل
  `elementor/element/{stack}/{section}/before_section_end`.

## تست

```bash
composer install   # فقط PHPUnit، ابزار توسعه — در ران‌تایم افزونه بارگذاری نمی‌شود
vendor/bin/phpunit
```

تست‌های `tests/Domain` و `tests/Service` (بخش تعطیلات هفته) خالص‌اند (بدون
نیاز به نصب وردپرس). پوشش شامل: کبیسه‌ی شمسی، مرز اسفند ۲۹/۳۰، نوروز،
round-trip تبدیل، عبور هفته از مرز ماه/سال شمسی، و کل زنجیره‌ی اولویت‌بندی
تعطیلی (override، انتخاب ماهانه، جمعه، عدم نشتی override به روز بعد).

تست‌های یکپارچگی (Cron، REST، wp_options واقعی) نیازمند بوت‌استرپ وردپرس
(`WP_UnitTestCase`) هستند و در این مخزن راه‌اندازی نشده‌اند. ویجت‌های Icon
Box/Price تست خودکار ندارند.

## نیازمندی‌ها

- PHP 8.1+ (هاست هدف فعلی PHP 8.1.25 است؛ عمداً به class-level `readonly
  class` و typed class constants که 8.2/8.3 می‌خواهند وابسته نشدیم)
- WordPress 6.4+
- Elementor 3.13+ (رایگان کافی است؛ در صورت وجود Elementor Pro تداخلی رخ
  نمی‌دهد — Visibility Condition مستقل از پرو کار می‌کند)
- WooCommerce (فقط برای ویجت قیمت)
