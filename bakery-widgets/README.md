# Bakery Elementor Widgets

افزونهٔ اختصاصی ویجت‌های المنتور برای بیکری عظام.

## ویجت‌ها

### آیکون، عنوان و توضیحات (`bakery-icon-box`)

ویجتی مشابه سطر معرفی ویجت‌های الماسارا (آیکون + عنوان)، با این تفاوت‌ها:

- خروجی از سه بخش مستقل تشکیل شده: **آیکون**، **عنوان** و **توضیحات**.
- تگ HTML عنوان (`h1`–`h6`, `div`, `span`, `p`) و تگ توضیحات (`p`, `div`, `span`) جدا از هم قابل تنظیم‌اند.
- ساختار مارک‌آپ عمداً **دو‌سطری** است:
  - سطر ۱ (`.bkw-icon-box__header`): آیکون و عنوان کنار هم.
  - سطر ۲ (`.bkw-icon-box__description`): توضیحات، زیر سطر اول.

  این جدایی تضمین می‌کند آیکون — هرقدر هم بزرگ باشد — هیچ‌وقت با ارتفاعش وارد سطر توضیحات نشود و همیشه فقط با عنوان هم‌تراز بماند. کنترل «هم‌تراز کردن توضیحات زیر عنوان» (روشن به‌طور پیش‌فرض) توضیحات را دقیقاً به‌اندازهٔ عرض آیکون + فاصله عقب می‌برد تا زیر عنوان بنشیند؛ خاموش کردنش توضیحات را تمام‌عرض (هم‌لبه با آیکون) می‌کند.
- چیدمان (جهت، تراز، فاصله‌ها، wrap) به‌صورت کامل ریسپانسیو از تب محتوا مدیریت می‌شود.
- تب استایل هر سه بخش را کامل پوشش می‌دهد: تایپوگرافی، رنگ عادی/هاور، پس‌زمینه (کلاسیک/گرادیانت)، حاشیه، رادیوس، سایه، پدینگ، رنگ fill/stroke آیکون SVG و مدت انیمیشن.
- آیکون از نوع تصویر یا SVG پشتیبانی می‌کند؛ SVG به‌صورت inline و پاک‌سازی‌شده (whitelist عنصر/ویژگی) رندر می‌شود تا رنگش از تب استایل قابل تغییر باشد.
- **جایگاه آیکون قابل انتخاب است**: کنار عنوان (پیش‌فرض) یا کنار توضیحات — یک آیکون، یک جایگاه؛ سبک‌ها (سایز، رنگ، پس‌زمینه، حاشیه و...) برای هر دو حالت مشترک است، فقط محل قرارگیری‌اش عوض می‌شود.
- لینک اختیاری روی کل باکس یا فقط عنوان.

### قیمت (`bakery-price`)

فقط نمایش قیمت محصول ووکامرس (بدون افزودن به سبد، بدون بج تخفیف):

- سه بخش مستقل: **قیمت فعلی**، **قیمت پیشین** (خط‌خورده، فقط هنگام فروش ویژه) و **واحد پول**.
- محصول متغیر: کمترین قیمت نمایش داده می‌شود (بدون قیمت پیشین، چون یک قیمت پیشین واحد برای چند گزینه معنا ندارد).
- **جایگاه و ترتیب کاملاً آزاد است**: هر سه بخش داخل یک فلکس‌ردیف‌اند؛ «جهت»، «تراز»، «فاصله» و «wrap» از تب چیدمان تنظیم می‌شوند، و هر بخش یک عدد «ترتیب نمایش» (CSS `order`) مستقل دارد — یعنی می‌توان مثلاً واحد پول را بین دو عدد یا در ابتدای همه گذاشت، بدون تغییر مارک‌آپ.
- تب استایل هر سه بخش را کامل پوشش می‌دهد: تایپوگرافی، رنگ، پس‌زمینه (کلاسیک/گرادیانت)، حاشیه، رادیوس، پدینگ. قیمت پیشین یک سوییچ «خط‌خورده» جدا هم دارد.
- قیمت صفر: به‌جای عدد، متن دلخواه («رایگان») نمایش داده می‌شود.

## نیازمندی‌ها

- PHP 7.4+
- WordPress 6.0+
- Elementor 3.13+
- WooCommerce (فقط برای ویجت قیمت)

## ساختار

```
bakery-widgets.php          فایل اصلی افزونه
includes/plugin.php         ثبت دسته‌بندی، ویجت‌ها و استایل‌ها
includes/svg.php            پاک‌سازی SVG برای درج inline (whitelist عنصر/ویژگی)
includes/widgets/icon-box.php  ویجت آیکون + عنوان + توضیحات
includes/widgets/price.php     ویجت قیمت
assets/css/bakery-widgets.css  استایل ساختاری (چیدمان پایه)
```
